# Waymark website

Static website for the local-first Waymark job-search application.

Built on Dossier by AienTech: https://github.com/AienTech/dossier

Redesigned and extended by Augustine Antony Joy. Licensed under AGPL-3.0; see LICENSE. Bundled Geist font license: fonts/OFL-geist.txt.

These HTML, CSS, JavaScript, and image files are the complete static website, ready for GitHub Pages. The application backend and personal data are not included. Desktop installers are not yet available.

Publish this directory to a public repository named <organization>.github.io under the selected neutral organization. In Settings > Pages select Deploy from a branch, main, / (root).
